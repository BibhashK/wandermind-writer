# Wandermind Writer

An AI agent that scouts trending tech topics, researches them across the live web,
writes an SEO-optimised article with real editorial craft, and publishes it straight
to your WordPress site as a draft — plus a matching LinkedIn post to promote it.

Bring your own API keys. Nothing is stored on our servers.

## Status

🚧 In development.

## Stack

- **Backend:** FastAPI + LangGraph
- **AI:** Google Gemini
- **Research:** Tavily
- **Frontend:** HTML / CSS / vanilla JS
